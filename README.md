# 페이먼츠 미션

우아한테크코스 레벨2 **페이먼츠** 미션 저장소이다.

이 저장소는 일부러 비어 있다. 크루는 프로젝트 부트스트랩부터 라이브러리 선택·설치·설정까지 직접 수행한다. "왜 이 라이브러리를 골랐는가"가 곧 학습이다.

## 프로젝트 초기화

[React — Build a React app from scratch](https://react.dev/learn/build-a-react-app-from-scratch)

```sh
npm create vite@latest my-app -- --template react-ts
npm install
npm run dev
```

# Step 1

## 기능 명세

### 카드 프리뷰

- [x] 입력한 카드 유효기간에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### 카드 번호 입력 및 식별

- [x] 카드 번호를 입력 받는다.
- [x] 카드 브랜드를 식별한다.
- [x] [예외] 숫자 외의 값이 입력되는 경우
- [x] [예외] visa, mastercard 외의 번호로 시작하는 경우
- [x] [예외] 한 입력 폼의 입력된 번호의 개수가 4개 미만일 때 포커스가 벗어난 경우
- [x] 입력한 카드 번호에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### 카드 유효기간 입력

- [x] 카드 유효기간을 입력 받는다.
- [x] [예외] 숫자 외의 값이 입력되는 경우
- [x] [예외] 월, 연도 범위를 벗어난 경우
- [x] [예외] 한 입력 폼의 입력된 번호의 개수가 2개 미만일 때 포커스가 벗어난 경우
- [x] [예외] 현재 날짜보다 과거의 날짜가 입력된 경우
- [x] 입력한 유효기간에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### CVC 입력

- [x] CVC 번호를 입력 받는다.
- [x] [예외] 숫자 외의 값이 입력되는 경우
- [x] [예외] 3자리가 아닌 경우
- [x] [예외] 한 입력 폼의 입력된 번호의 개수가 3개 미만일 때 포커스가 벗어난 경우

# Step 2

## 추가 사항
- [x] 카드 회사(BC, 신한 등) 추가
- [x] 카드 브랜드(아메리칸 익스프레스, 유니온페이 등) 추가
- [x] 동적 UI로 변경, 사용자는 한번에 하나의 입력필드에 집중가능
- [x] 카드 회사에 따른 카드 프리뷰 색상 변경
- [x] 비밀번호 입력 섹션 추가
- [x] 제출 버튼 추가
- [x] 제출 이후 페이지 이동(Routing 추가)
- [X] Custom Hook 도입

## 기능 명세

### 동적 UI
- [x] 섹션별 입력필드들은 한번에 하나씩 차례대로 노출된다(현재 노출된 필드에 유효한 값을 입력하면 다음 필드가 노출된다)

### 카드 번호 입력 및 식별
- [x] 입력받은 번호로 추가된 카드 브랜드도 식별한다
- [x] 식별된 브랜드에 따라 사용자가 입력할 수 있는 입력 필드의 개수가 바뀐다

### 카드사 입력
- [x] 드롭다운으로 선택할 수 있는 카드사를 보여준다
- [x] 카드사가 입력되면 카드 프리뷰 색상이 변경된다

### 비밀번호 입력
- [x] 비밀번호 앞 두자리를 입력받는다
- [x] 입력받는 숫자는 *로 전환되어 화면에 나타난다

### 제출 버튼 클릭
- [x] 모든 섹션에 유효한 값이 입력되면 제출 버튼이 나타난다
- [x] 제출 버튼 클릭 시 제출 완료 페이지로 이동된다

### 제출 완료 페이지
- [x] 첫번째 인풋필드의 카드번호와 선택된 카드사 정보가 나타난다
- [x] 확인 버튼을 누르면 다시 처음으로 돌아간다
