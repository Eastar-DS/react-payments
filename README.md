# 페이먼츠 미션

우아한테크코스 레벨2 **페이먼츠** 미션 저장소이다.

이 저장소는 일부러 비어 있다. 크루는 프로젝트 부트스트랩부터 라이브러리 선택·설치·설정까지 직접 수행한다. "왜 이 라이브러리를 골랐는가"가 곧 학습이다.

## 프로젝트 초기화

[React — Build a React app from scratch](https://react.dev/learn/build-a-react-app-from-scratch)

```sh
npm create vite@latest my-app -- --template react-ts
npm install
npm run dev
```

## 기능 명세

### 카드 번호 입력 및 식별

- [ ] 카드 번호를 입력 받는다.
- [ ] 카드 브랜드를 식별한다.
- [ ] [예외] 카드 번호는 숫자만 입력 가능하다.
- [ ] [예외] visa, mastercard 외의 번호는 "올바른 카드번호를 입력해주세요" 메세지 출력한다.
- [ ] 입력한 카드 번호에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### 카드 유효기간 입력

- [ ] 카드 유효기간을 입력 받는다.
- [ ] [예외] 카드 유효기간은 숫자만 입력 가능하다.
- [ ] [예외] 카드 유효기간은 월, 연도 범위 내에서 입력 가능하다.

- [ ] 입력한 카드 유효기간에 따라 카드 프리뷰를 실시간으로 업데이트한다.

### CVC 입력

- [ ] CVC 번호를 입력 받는다.
- [ ] [예외] CVC 번호는 숫자만 입력 가능하다.
